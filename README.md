# Ширик-камера

Приложение на Camera2: показывает, что реально умеет каждый модуль камеры (включая скрытые ID и физические модули внутри логической камеры), и пишет видео в любом режиме, который пропустит драйвер. Режимы, которых нет в драйвере (4K, 60 к/с), можно запросить принудительно. Если драйвер откажет, приложение так и напишет.

После записи приложение показывает реальные разрешение и частоту кадров файла. Видео сохраняются в Movies/WideCam.

## Скачать

С телефона: **Releases** (справа на странице репозитория) → последний релиз → `WideCam.apk`.
